# FlutterLab

منصة عربية مفتوحة لتعلّم Flutter Widgets من خلال الشرح والأمثلة العملية.

## التشغيل
افتح `index.html` عبر خادم محلي أو انشر المستودع على Vercel كـ Static Site.

## ملاحظات
يتضمن المشروع فهرساً تعليمياً، بحثاً وتصنيفات، أمثلة مدمجة، ونافذة تشغيل تعتمد على DartPad. تشغيل الأمثلة يتطلب اتصالاً بالإنترنت، وبعض واجهات Flutter التي تعتمد على عتاد الجهاز لا تعمل داخل المتصفح.
